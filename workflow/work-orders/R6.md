## Goal
A participant can record purchases (by hand, from a wishlist entry marked bought, from the catalogue, or from a scanned receipt whose personal details are masked before anything is stored), see prices in the original currency with a dated conversion, plan wishlist purchases by month, pick items from a seed catalogue (also from "start from popular items" at onboarding and by barcode) shown as tinted category illustrations with a source link; an admin keeps the source register, reviews unmapped items and takes a source down in one action; the collector honours robots.txt and the rate limit, proven against a local test server only. Export includes receipts and their files; Leave the pilot removes them.

## Glossary
- "Counted lines": changed lines per `git diff --numstat` against the base, excluding package-lock.json, JSON data files (mapping tables, fixture ground truth), evidence and screenshots. Tests count. A maker whose estimate passes 650 before starting tells the orchestrator, who splits the work order; one that passes 650 while building says so in the report.
- "Synthetic": produced by code in this repository from a fixed seed, with invented names; never copied from a real receipt, storefront page, person or brand.
- "Local test HTTP server": `http.server` bound to 127.0.0.1 on an ephemeral port, started and stopped by the test (rule 11), serving the hand-written synthetic pages under `jobs/collector/tests/site/`. "Live website": any other host.
- "Style" in the picker (FR-21, undefined in the FDD data dictionary): fit, pattern or occasion tag.
- "Redaction tokens" (LLD 7.4): `[card]`, `[email]`, `[phone]`, `[id]`; address and postcode lines are dropped, not masked.
- "GTIN-14": digits only, accepted lengths 8, 12, 13 or 14 (LLD 8.2), left-padded with zeros to 14; stored in that form in `catalog_items.gtin` and `items.barcode`.
- "Rate date": `rate_date` of the `ops.fx_rates` row used; conversion = amount / per_usd[from] * per_usd[to], shown only when both currencies have a row.
- "Fixture expectation": see CC10; LLD 11 names the 30-receipt set but no number.

## Document points found while writing this spec (for doc-sync; not changed here)
- Workflow R6 row requires a parser threshold "never below the LLD 11 fixture expectation", but LLD 11 gives no number (CC10 sets one).
